# About Fluent Fold

**Version:** 1.1.0-beta  
**Developer:** Hamma  
**Platform:** Windows 10+ (build 17763)  
**Runtime:** .NET 10.0 + Windows App SDK 2.3.1  
**UI Framework:** WinUI 3  
**License:** MIT  

---

Fluent Fold is a modern file organization tool built for Windows 11. It automatically categorizes files into folders by type — Images, Documents, Videos, Audio, Archives, Code, and Other — with support for custom rules, bulk renaming, and one-click undo.

### Key Features

- **Auto-categorize** — Scan any folder and sort files by type
- **Bulk Rename** — Pattern-based renaming with sequential numbering
- **Custom Rules** — Extension and trigger-based categorization
- **Pro Mode** — Advanced controls with custom rules, triggers, and folder naming patterns
- **Undo / Restore** — Revert any organization operation instantly
- **Storage Analysis** — Duplicate detection, temp file cleanup, and disk usage dashboard
- **Dark & Light Theme** — Follows system preference or manual toggle
- **Teaching Tips** — Optional guided tips on action buttons

### Distribution

- **Microsoft Store** (sideload MSIX packages for x64, x86, ARM64)
- **Inno Setup Installer** — Admin install with Start Menu and Desktop shortcuts
